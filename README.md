# Comparing-Multiple-Models-on-the-UNSW-NB15-Data-Set
Completely explained in the report next to the main project 
I tried some of the models on the data set that is provided in (IGRF-RFE: a hybrid feature selection method for MLP-based network intrusion detection on UNSW-NB15 dataset) paper and tried to achieve to better accuracy

## Code guide

`main.ipynb` loads and visualizes UNSW-NB15 data, applies preprocessing and feature selection (including PCA and recursive feature elimination), and compares classifiers. `Final_Project_Report.pdf` explains the study; the PNG files are generated figures. Open the notebook in Jupyter, provide the dataset paths referenced by its cells, and run the cells in order. Results in the report are historical and were not regenerated for this README.
